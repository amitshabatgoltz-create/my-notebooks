# המחברות שלי 📓

אתר של מחברות דיגיטליות. נרשמים עם אימייל וסיסמה (או עם חשבון Google), ואז:
- רואים את כל המחברות במסך אחד
- יוצרים מחברות חדשות ובוחרים להן צבע
- כותבים ומעצבים: כותרות, מודגש, קו תחתון, מרקר ורשימות
- מוסיפים תמונות (מהמחשב, מהמצלמה בטלפון, או בהדבקה)
- יוצרים טבלאות בכל גודל, ומוסיפים או מוחקים שורות ועמודות
- **יומן**: לוח חודשי שבו רושמים מבחנים, שיעורי בית, אירועים ותזכורות, מסמנים מה כבר נעשה ורואים מה מחכה בימים הקרובים
- **✨ סיכום למבחן**: לחיצה אחת יוצרת סיכום של המחברת עם בינה מלאכותית (Gemini), כולל קריאה של תמונות של דפי מחברת
- הכל נשמר אוטומטית בענן, ואפשר להיכנס מכל מחשב או טלפון

כל משתמש רואה רק את המחברות והיומן שלו.

## הוראות התקנה (פעם אחת, בערך 15 דקות)

### שלב 1: יצירת פרויקט ב-Firebase (השמירה וההתחברות)
1. נכנסים ל-https://console.firebase.google.com ומתחברים עם חשבון Google.
2. לוחצים **Create a project** (יצירת פרויקט), נותנים שם (למשל `my-notebooks`) וממשיכים. את Google Analytics אפשר לכבות.

### שלב 2: הפעלת התחברות
1. בתפריט בצד: **Build ← Authentication ← Get started**.
2. בלשונית **Sign-in method**:
   - מפעילים את **Email/Password**.
   - מפעילים את **Google** (בוחרים אימייל תמיכה ושומרים).

### שלב 3: יצירת מסד הנתונים
1. בתפריט: **Build ← Firestore Database ← Create database**.
2. בוחרים מיקום (למשל `europe-west`) ו-**Start in production mode**.
3. נכנסים ללשונית **Rules**, מוחקים את מה שיש שם, מדביקים את כל התוכן של הקובץ `firestore.rules` ולוחצים **Publish**.

### שלב 4: חיבור האתר ל-Firebase
1. לוחצים על גלגל השיניים ⚙️ ליד **Project Overview ← Project settings**.
2. למטה, ב-**Your apps**, לוחצים על הסמל `</>` (Web), נותנים שם ולוחצים **Register app**.
3. מעתיקים את מה שמופיע בתוך `const firebaseConfig = { ... }`.
4. פותחים את הקובץ `firebase-config.js` ומחליפים את כל ה-`PASTE_HERE` בערכים שהעתקתם.

> ההגדרות האלה לא סודיות, ומותר שיהיו ב-GitHub. מה ששומר על המחברות הוא כללי האבטחה משלב 3.

### שלב 5: העלאה ל-GitHub ופרסום האתר
1. יוצרים repository חדש ב-GitHub (למשל `my-notebooks`) ומעלים אליו את כל הקבצים: **Add file ← Upload files**.
2. נכנסים ל-**Settings ← Pages**.
3. ב-**Source** בוחרים **Deploy from a branch**, ב-Branch בוחרים `main` ו-`/ (root)` ולוחצים **Save**.
4. אחרי דקה-שתיים האתר יהיה זמין בכתובת:
   `https://<שם-המשתמש-שלך>.github.io/my-notebooks/`

### שלב 6: אישור הכתובת ב-Firebase (חשוב!)
1. ב-Firebase: **Authentication ← Settings ← Authorized domains ← Add domain**.
2. מוסיפים: `<שם-המשתמש-שלך>.github.io`

### שלב 7: הפעלת "סיכום למבחן" (בינה מלאכותית, חינם)
1. ב-Firebase, בתפריט: **AI services ← AI Logic ← Get started**.
2. בוחרים **Gemini Developer API** (החינמי, לא Agent Platform / Vertex) ולוחצים **Get started with this API** / **Enable**.
3. אם מופיע שלב של **App Check**: אפשר לדלג עליו. אם הסיכום לא עובד ומופיעה הודעה על App Check, נכנסים ל-**Security ← App Check ← APIs ← Firebase AI Logic** ולוחצים **Unenforce**.

זהו! נכנסים לאתר, לוחצים **הרשמה**, ואחרי הכניסה אפשר ללחוץ על "להוסיף את מחברת תנ"ך כדוגמה".

## בעיות נפוצות
- **"צריך להדביק את הגדרות Firebase"**: לא החלפתם את `PASTE_HERE` בקובץ `firebase-config.js`.
- **"האתר הזה לא מאושר ב-Firebase"**: לא עשיתם את שלב 6.
- **"לא ניתן לטעון את המחברות"**: כללי האבטחה משלב 3 לא פורסמו.
- **"צריך לעדכן את כללי האבטחה" בשיתוף**: הכללים התעדכנו כשנוסף שיתוף עם חברים. מדביקים שוב את כל `firestore.rules` בלשונית Rules ולוחצים Publish.
- **כניסה עם Google של משרד החינוך לא עובדת**: ייתכן שמשרד החינוך חוסם אתרים חיצוניים. במקרה כזה נרשמים עם אימייל וסיסמה (אפשר גם עם כתובת של משרד החינוך).
- **בדיקה במחשב**: אי אפשר לפתוח את `index.html` בלחיצה כפולה, צריך שרת. אפשר להריץ `python -m http.server` בתיקייה ולהיכנס ל-`http://localhost:8000`.
